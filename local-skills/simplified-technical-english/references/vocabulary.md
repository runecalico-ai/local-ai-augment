# ASD-STE100 Vocabulary Reference

## Core Principles

ASD-STE100 Part 2 is a dictionary of ~900 approved general words (Issue 9, 2025).

**How the dictionary works:**
- **UPPERCASE entry** = approved word (use with the defined meaning and part of speech only)
- **lowercase entry** = word not approved (dictionary gives approved alternative)
- Each approved word has exactly one permitted meaning and one permitted part of speech
- Technical names and verbs specific to your industry are permitted under rules 1.5 and 1.12

**American English spelling used throughout (Merriam-Webster).**

> **Important:** The full ASD-STE100 dictionary is proprietary. The substitutions below are representative examples widely cited in STE training and reference materials. To determine definitively whether a specific word is approved, consult the official specification.

## Approved Substitutions

### Obligation and Possibility

| Not STE | Use Instead | Reason |
|---------|-------------|--------|
| shall | must | "must" is the approved word for obligation |
| may (possibility) | can | "can" is used for capability and possibility |
| should | must / can | Ambiguous — choose the precise meaning |

### Common Unapproved Words

| Not STE | Use Instead |
|---------|-------------|
| ensure | make sure |
| utilize / utilise | use |
| demonstrate | show |
| obtain | get |
| require | need |
| indicate | show |
| perform | do (or use the specific verb: "run", "check", "clean") |
| prior to | before |
| subsequent to | after |
| in order to | to |
| in the event that | if |
| in accordance with | follow [document name] / as stated in [document] |
| at this point in time | now |
| commence / initiate / begin | start |
| terminate / conclude | stop / end |
| attempt | try |
| assist | help |
| about (used to mean "approximately") | approximately / around |
| verify | check (to look at something to find if it is correct or in good condition) or make sure (to confirm a condition is met) |
| acceptable | correct / good |

### Nominalization (Verb-as-Noun) — Avoid

Replace noun-heavy phrasing with the direct verb form:

| Not STE | Use Instead |
|---------|-------------|
| perform a check | check |
| carry out an installation | install |
| make an adjustment | adjust |
| do a removal | remove |
| conduct an inspection | inspect |
| provide confirmation | check / make sure |

## One-Word-One-Meaning Examples

STE selects one word from a group of synonyms. Examples of preferred words:

| STE Word | Excluded Synonyms (do not use) |
|----------|-------------------------------|
| start | begin, commence, initiate, originate |
| stop | terminate, cease, discontinue |
| use | utilize, employ, apply |
| remove | detach, take off, extract, disengage |
| install | fit, mount, attach, place |
| get | obtain, acquire, retrieve |
| show | indicate, demonstrate, display |
| check | verify, confirm, validate, ensure |
| before | prior to, preceding, in advance of |
| after | subsequent to, following, upon completion of |

## Technical Names and Verbs (Rules 1.5 and 1.12)

Words not in the dictionary may be used as technical names or technical verbs when:

1. They are standard in your industry (e.g., "torque", "rivet", "propeller")
2. They are company- or project-specific and **defined in a glossary or on first use**
3. They are recognized system or product names (e.g., "aural warning system", "overhead panel")

**Rules:**
- Define on first use: "the fuel control unit (FCU) controls the fuel flow"
- Use the same term consistently — no synonyms even for technical names
- Recognized system names may exceed the 3-word noun cluster limit (exception to rule 2)

## "-ing" Form Usage

The `-ing` form is restricted. Use it **only** as:

| Permitted Use | Example |
|---------------|---------|
| Technical noun (a formally named task) | "the Cleaning" (only when formally named in documentation — capitalize to distinguish from generic use) |
| Modifier in a recognized technical compound | "the operating temperature", "the programming mode", "the cleaning agent" |

> **What counts as a recognized technical compound:** The compound must appear as a fixed term in your project glossary, a governing specification (e.g., S1000D, ATA iSpec 2200), or an industry-standard reference for your domain. Do not create new `-ing` modifier compounds — only use ones already established in your documentation or industry.

**Not permitted:**
- Present continuous tense: ❌ "is removing"
- Gerund as sentence connector: ❌ "Before removing the cover, disconnect the power."
  → ✅ "Disconnect the power. Then remove the cover."
- Participial phrase: ❌ "Using a wrench, tighten the bolt."
  → ✅ "Use a wrench. Tighten the bolt."

## Passive Voice

| Context | Rule |
|---------|------|
| Procedures (instructions) | Use **active voice always** — say who does the action |
| Descriptive writing | Use active voice; use passive **only if the agent is unknown** |

**Example:**
- ❌ Procedure passive: "The valve must be closed." → ✅ "Close the valve." (or "The technician closes the valve.")
- ✅ Descriptive passive (agent unknown): "The data is transmitted to the receiver." (if you don't know or need to specify who transmits)
